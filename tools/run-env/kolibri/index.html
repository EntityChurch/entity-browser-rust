The floppy drive

Files move through a floppy disk in drive A (/fd/1 inside KolibriOS). It holds 1.44 MB, and its files are kept between visits (in the entity tree, under this app's workspace, floppy/). Put a file in and it appears there; save a file there from KolibriOS and take it out here. A file taken out goes to File Transfer. Every window of this machine shares these files, but each reads them when it starts: Reload floppy picks up what another window saved.
