# The package set the Alpine Environment can `apk add` with no network.
#
# One Alpine package name per line (or several per line); `#` starts a comment.
# build-packages.sh fetches every name here PLUS its dependency closure from
# Alpine v3.21 (x86), drops what the image already ships at the same version,
# and signs the index. A visitor downloads only what they install; the cost of a
# longer list is hosting and publish time (PLAN-2026-09-13-THE-VM-RELEASE §5, D4).
#
# THE RULE FOR WHAT GOES IN: useful with no network, on files you move in and
# out; small; exists for 32-bit x86. Nothing that only talks to a network (curl,
# wget, ssh clients): the machine has none, so they install and do nothing.
#
# Sizes are download MiB for what each group ADDS, dependencies included,
# measured against the 3.21 x86 index on 2026-09-14 (a resolver over APKINDEX;
# the real build is authoritative and has come out ~10% larger). The survey,
# with what was left out and why: PLAN-2026-09-13-THE-VM-RELEASE §10.
