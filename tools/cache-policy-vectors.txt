# Cache-immutability vectors — the SHARED specification for C15.
#
# The rule ("may these bytes be cached `max-age=31536000, immutable`?") has four
# expressions in three languages and they cannot all be one function:
#
#   1. src/cache_policy.rs                 — the canonical Rust rule
#   2. src-tauri/src/app_server.rs         — `include!`s (1) verbatim
#   3. tools/cors-serve.py                 — the dev/CDN reference server (Python)
#   4. docs/PUBLISHING-QUICKSTART.md §6.2  — the CDN recipe an operator copies
#
# So they are pinned to THIS FILE instead. `cache_policy`'s unit tests read it,
# and `tools/cache-policy-lint.sh` (in `make lint`) runs the Python expression
# over the same lines. Two implementations that cannot disagree without a red
# gate is what "one rule" reduces to across three languages — a comment asking
# the next author to keep them in step is what drifted (REVIEW-2026-08-25 §2.1).
#
# Format: `immutable|mutable  <request target>`, `#` comments, blank lines ok.
# Targets are request targets, not filenames: a query string is part of the
# input, because testing the raw target instead of the path was one of the four
# divergences.
#
# ADDING A VECTOR IS THE CHEAP HALF OF FIXING A CACHE BUG. Put the failing path
# here first; it lands in the Rust gate and the Python gate in the same commit.
